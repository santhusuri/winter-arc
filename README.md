# ❄️ Winter Arc — Personal Growth & Finance Tracker

Winter Arc is a personal productivity and self-improvement dashboard designed to track daily habits, personal growth, cybersecurity learning, tasks, goals, and financial progress in one place.

The project is built as a lightweight web application that can run locally in a browser and is designed with a mobile-friendly interface.

## 🎯 Purpose

The goal of Winter Arc is to make daily progress measurable and consistent.

Instead of relying on motivation alone, the dashboard provides:

- Daily habit tracking
- Personal growth tracking
- Cybersecurity learning tracking
- Weekly progress analysis
- Goal tracking
- Financial tracking
- Financial Independence (FI) planning
- Net-worth tracking
- Spending analysis

> "Don't give up. Try again. Every day is another chance to become better."

---

## 🧭 Main Sections

### 🏠 Today

A daily dashboard where tasks and habits can be checked off as they are completed.

The dashboard displays:

- Today's completion percentage
- Completed habits
- Remaining habits
- Freeze tokens
- Building Myself habits
- Growing habits

---

### 🧱 Building Myself

The Building Myself section focuses on improving personal discipline and physical/lifestyle habits.

Examples include:

- Wake up at 6 AM
- Workout
- 10K steps
- Drink 2L water
- Read
- Journaling
- Meditation
- Sleep/daily routine
- No sugar and junk food

---

### 🚀 Growing

The Growing section focuses on professional and intellectual development.

Current areas include:

- Social-media screen time below 3 hours
- Interview preparation
- Cybersecurity study
- Daily video creation
- Practising learned concepts

The purpose is to continuously improve technical knowledge, career readiness and practical skills.

## 📅 Habit Grid

The Habit Grid provides a calendar-style view of daily habit completion.

It allows progress to be viewed across:

- Daily
- Weekly
- Monthly

Each habit can be checked off for the corresponding day, making consistency easier to visualize.

# 💰 Finance

The Finance section acts as a personal finance and Financial Independence dashboard.

It tracks:

### Monthly Finance

- Monthly income
- Monthly expenses
- Monthly savings
- Savings rate
- Expense budget
- Budget usage

### Net Worth

Net worth is calculated using:

**Net Worth = Total Assets − Total Liabilities**

Assets can include:

- Bank savings
- Mutual funds
- Stocks
- EPF
- Cash
- Other investments

Liabilities can include:

- Loans
- Credit card balances
- Other debts

### 📈 Financial Independence

The FI planner tracks:

- Current net worth
- FI target
- Annual expenses
- Safe Withdrawal Rate
- Estimated FI corpus
- FI progress
- Emergency fund
- Emergency-fund target

Estimated FI corpus is based on annual expenses and the selected Safe Withdrawal Rate.

### 📒 Transactions

Transactions can be recorded as:

- Income
- Expense
- Investment

Each transaction can include:

- Date
- Amount
- Category
- Description

### 📊 Spending Breakdown

Expenses can be grouped by category to identify where money is being spent and which areas may need attention.

# 📊 Weekly Report

Winter Arc includes a weekly progress analysis.

The report evaluates actual habit completion and identifies:

- Overall consistency
- Building Myself performance
- Growing performance
- Strongest habits
- Habits that need improvement
- Areas requiring more concentration
- Next week's focus

The idea is not simply to show whether a task was completed.

It helps answer:

> **What am I lacking?**

and

> **What should I concentrate on next week?**

This makes the tracker useful for continuous self-improvement rather than simple checkbox tracking.

---

# ❄️ Freeze Tokens

Freeze tokens provide a way to protect a habit streak when a habit cannot be completed on a particular day.

The dashboard displays:

- Total freeze tokens
- Remaining freeze tokens
- Token usage

# 🛠️ Technology

The project currently uses:

- HTML
- CSS
- JavaScript
- Browser Local Storage

---

# 💾 Data Storage

The application can maintain data locally using browser storage.

Google Sheets integration can be used as an external data-storage/synchronization layer.

The intended architecture is:

Browser
↓
Winter Arc Web App
↓
Local Storage
↓
Google Apps Script
↓
Google Sheets

This allows the application to remain lightweight while providing an option for persistent cloud-based data storage.
